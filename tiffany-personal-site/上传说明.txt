个人网站文件已准备好。请把 index.html、style.css 和 assets 文件夹中的内容上传到 GitHub 仓库的最外层（不要把整个文件夹嵌套进去）。

发布步骤：
1. 打开你的 tiffanywinglun.he.github.io 仓库。
2. 点击 “Add file” → “Upload files”。
3. 将 index.html、style.css、research 文件夹和 assets 文件夹拖入上传区，然后提交更改（Commit changes）。
4. 打开仓库 Settings → Pages，在 “Build and deployment” 中选择 “Deploy from a branch”；Branch 选 main，文件夹选 /(root)，点击 Save。
5. 等待 GitHub Pages 发布，访问 https://tiffanywinglun.he.github.io

替换个人资料：
- 个人照片：把照片放进 assets，命名 profile.jpg
- 简历：放入 assets，命名 resume.pdf
- 作品：放入 assets，命名 art-1.jpg、art-2.jpg、art-3.jpg
- 论文：每个学科有单独页面，在 research 文件夹里编辑对应 HTML。把论文 PDF 放入 assets/papers/，并按页面里的文件名链接；页面内的题目、作者、年份和摘要都可以直接替换。
- 邮箱：打开 index.html，将所有 your.email@example.com 换成你的邮箱
- 文案：在 index.html 里编辑英文文字，也可以改成中文

网站使用蓝色星空背景图 blue-universe.jpg。若要公开发布，请确认你有权在个人网站使用该图片。
